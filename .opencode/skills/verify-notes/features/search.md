# search

## Sub-features

- `keyboard` typing into the search box filters the list live, with no submit.
  Type into the textbox labelled "Search notes". Do not press Enter and do not
  click Search. The list must narrow as you type.
- `empty-state` typing a query that matches nothing shows a status message.
  Type a query with no matches. The list must empty and a status reading
  "No matching notes" must appear.
